# AquaSense

### Turning Invisible Microplastic Interactions into Visible Signals

AquaSense is a **digital proof-of-concept** that simulates a proposed microplastic screening mechanism based on a **CaCO₃ nanoparticle-stabilized Pickering emulsion**.

## ⚠️ Scientific disclaimer

This project is a digital proof-of-concept simulation of a proposed sensing mechanism. It is **not experimentally validated** and does **not provide real microplastic detection results**. The parameter relationships are conceptual and require experimental calibration and validation.

## How to run

```bash
npm install
npm run dev
```

Then open the local address shown by Vite in your browser.

CaCO₃ Nanoparticles → Pickering Emulsion Interface → Simulated Microplastic Interaction → Simulated Interface Disturbance → Simulated Dye/Colour Response → Digital Screening Output
